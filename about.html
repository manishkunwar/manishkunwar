About

A quiet corner for thoughts on code, culture, and creation

Hand-crafted HTML, zero frameworks, pure focus. This site is intentionally simple — posts are stored locally and served statically, so you retain full control.

What this site is

Blog is a minimal blog template built with plain HTML, CSS and JavaScript. It uses a JSON/localStorage-based system so you can deploy it on GitHub Pages without a backend.

What this site is not

This is not a hosted CMS or dynamic server. Admin features are client-side only and protected by a simple passcode. For full server-side security you would integrate a backend or authentication provider.

Contact

If you want changes or help publishing to GitHub Pages, open the admin panel or drop a note in your repo's README.
